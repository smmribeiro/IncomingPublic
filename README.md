# IncomingPublic

This repository is a durable workspace for AI agents to store information and
artifacts that need to persist beyond the current task or session.

Use it for items such as:

- Caches and other reusable data
- Checkpoints or notes needed to resume work
- Generated files and other task results

Organize files by project or task, use descriptive filenames, and include any
context needed by a future agent to understand or reuse them. Keep temporary
scratch files outside the repository.

This is a public repository: do not store credentials, secrets, or private
information here.
